
## Git – Kom igång
- 1 Öppna Bash

- 2 Gå till en mapp:
bash
cd mappnamn

- 3 Koppla till ett Git-repo
bash
git clone REPO-LÄNK (exempel: https://github.com/siggekolerud/Git-Github-Lab1.git)

- 4 Gå in i projektet
bash
cd projektnamn

- 5 Kontrollera status
bash
git status

- 6 Spara ändringar
bash
git add .
git commit -m "Min ändring"

- 7 Skicka ändringar till GitHub
bash
git push

- 8 Hämta senaste ändringarna
bash
git pull

## Vanliga Git-kommandon
Kommando	Betydelse
- git clone:	Kopiera ett repo
- git status: Kontrollera status
- git add:	Förbered ändringar
- git commit: Spara ändringar
- git push:	Skicka upp ändringar
- git pull:	Hämta ändringar
